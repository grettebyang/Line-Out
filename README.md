# Line Out (WIP)

### About the Game

Line Out is a chaotic couch co-op game where you and up to 3 friends each control a dog on a dog sledding team that delivers fika (coffee and pastries) in Swedish Lappland. You must cooperatively navigate through the snowy terrain and avoid obstacles so as to not destroy the fika package in your sled and deliver it to the customer as fast as you can.

The game is planned to launch for free December 2026
